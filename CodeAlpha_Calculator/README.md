##Basic Calculator##

This is a Basic Calculator built using HTML, CSS, and JavaScript. It performs basic Arithmetic Operations like Addition, Subtraction, Multiplication, and Division. The Calculator is designed with a clean User Interface, handles user input efficiently, and displays results in real time.

Features :
- Perform basic arithmetic operations.
- Real-time result display.
- Clear screen (AC) functionality.
- User input handling.
- Simple and clean UI design.
- Responsive layout.
  
Functionalities :
- Number input through buttons
- Operator selection (+, −, ×, ÷)
- Instant calculation on display
- clear screen option
 
Technologies Used :
- HTML – Used to create the structure of the calculator.
- CSS – Used for styling, layout design, and making the user interface responsive.
- JavaScript – Used to handle user input, perform calculations, and display results in real time.
