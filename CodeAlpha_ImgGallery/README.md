#CodeAlpha Image Gallery

This is a simple Image Gallery built using HTML, CSS, and JavaScript.
It shows a collection of images in a neat layout and makes it easy for users to interact with them.

Features :
- Responsive Design: Looks good on all devices – desktop, tablet, or mobile.
- Image Grid: Images are arranged in a clean grid, and you can click any image to see it bigger.
- Hover Effects: Simple CSS effects make the gallery feel interactive.
- Interactive Elements: JavaScript adds features like opening images in a full-screen view and smooth animations.

How It Works
- Uses CSS Grid to arrange images in rows and columns.
- JavaScript handles interactive things like opening images in a lightbox.
- The interface is simple and easy to navigate.

Built With
- HTML – for the structure
- CSS – for styling and layout
- JavaScript – for interactive features
