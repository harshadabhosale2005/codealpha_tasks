**Personal Portfolio**

This is a personal portfolio website created using HTML, CSS, and optional JavaScript. It is designed to showcase my skills, projects, resume, and contact information in a clean and professional manner. The layout is responsive, ensuring it looks great. This portfolio also includes smooth scrolling, animations, and hover effects for an enhanced user experience.

Features :
- Responsive Design: Looks good on any screen.
- Smooth Scroll: The website includes a smooth scrolling feature to enhance navigation between sections.
- Hover Effects: Interactive hover effects on buttons and images to make the website more engaging.
- Animations: Subtle animations are used to highlight content as you scroll.

Sections:
- About Me: A brief introduction of myself.
- Projects: A collection of my personal and professional projects, including brief descriptions.
- Resume: An interactive section displaying my CV.
- Contact Information: A contact details for visitors to reach out to me.

Technologies Used :
- HTML: To structure the content and sections of the portfolio.
- CSS: For styling the layout and applying animations, hover effects, and responsive design.
- JavaScript: Used for additional interactivity, such as smooth scrolling and animations.
